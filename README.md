# ann grow-ielts

词序 · IELTS 词汇自学网页，含动态小熊、刷题复习和离线使用包。

## 下载与使用

下载 **[ann-grow-ielts-v3.zip](ann-grow-ielts-v3.zip)**，解压后用 Chrome、Edge 或 Safari 打开 `index.html`，无需安装依赖。

也可以下载仓库内的 [index.html](index.html) 单独使用。学习进度保存在当前浏览器，换电脑时使用页面底部的「导出进度」和「恢复备份」迁移。

## 主要功能

- 8000 个英汉基础词条，发音、收藏、拼写和间隔复习。
- 多例句、词形高亮、整句朗读、译文切换与语料填空。
- TXT / JSON 文章批量导入、分句、去重及导入语料频次统计。
- 动态小熊按学习操作切换工作、玩耍和提醒状态。
- 默认 90 秒无学习操作后自己玩，5 分钟后温和提醒；时间可调，也可休息 10 分钟免打扰。
- 签到小院、莓果奖励、15 分钟专注计时和真实签到足迹。

## 内容范围

8000 个基础词条不等同于经过全套雅思真题统计的 8000 高频词。当前仅内置 7 条剑桥官方公开试读短句，尚未实现每词配多条真题例句；可导入自己提供的文章补充。章节初分、部分词义拓展仍待人工核验。

频率标签来自通用语料排名，非雅思官方等级。小熊采用本地规则回复，不能进行开放式智能对话或评定雅思分数。发音能力取决于浏览器和系统语音包。
